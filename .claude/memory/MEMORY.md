# Memory index — GolfBuddy

One line per memory: `- [Title](file.md) — hook`. Keep under ~200 lines / ~22 KB (past ~24 KB the tail is cut from
context). Every memory is one fact, committed. Loaded from CLAUDE.md (`@.claude/memory/MEMORY.md`).
Observatory's fleet board parses this file — keep the path and the one-line format.
